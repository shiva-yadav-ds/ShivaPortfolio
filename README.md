# Shiva Yadav | Data Scientist Portfolio

A stunning 3D portfolio website built with React, Three.js, and TailwindCSS, showcasing my journey and projects as a Data Scientist and Python Developer from IIT Madras.

![Portfolio Preview](/public/logo.png)

## 🚀 Features

- **3D Visuals**: Immersive 3D graphics powered by Three.js and React Three Fiber.
- **Responsive Design**: Fully responsive layout ensuring a great experience on all devices.
- **Interactive UI**: Smooth animations and transitions using Framer Motion.
- **Contact Form**: Functional contact form integrated with EmailJS.
- **Modern Tech Stack**: Built with the latest web technologies for performance and scalability.

## 🛠️ Tech Stack

- **Frontend**: [React](https://reactjs.org/), [Vite](https://vitejs.dev/)
- **Styling**: [TailwindCSS](https://tailwindcss.com/)
- **3D Graphics**: [Three.js](https://threejs.org/), [React Three Fiber](https://docs.pmnd.rs/react-three-fiber)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Routing**: [React Router](https://reactrouter.com/)

## 📦 Getting Started

### Prerequisites

Ensure you have [Node.js](https://nodejs.org/) installed on your machine.

### Installation

1.  Clone the repository:
    ```bash
    git clone https://github.com/shiva-yadav-ds/Shiva-Portfolio.git
    cd Shiva-Portfolio
    ```

2.  Install dependencies:
    ```bash
    npm install
    ```

### Running Locally

Start the development server:

```bash
npm run dev
```

The application will be available at `http://localhost:5173`.

### Building for Production

Build the project for production:

```bash
npm run build
```

The build artifacts will be stored in the `dist` directory.

## 🚀 Deployment

This project is configured for easy deployment on **Netlify** and **Vercel**.

### Netlify

A `netlify.toml` file is included to handle Single Page Application (SPA) routing.

1.  Push your code to a GitHub repository.
2.  Log in to Netlify and "Import from Git".
3.  Select your repository.
4.  Netlify should automatically detect the settings from `netlify.toml`.
5.  Click "Deploy".

### Vercel

A `vercel.json` file is included to handle SPA routing.

1.  Push your code to a GitHub repository.
2.  Log in to Vercel and "Add New Project".
3.  Select your repository.
4.  Vercel should automatically detect the framework (Vite).
5.  Click "Deploy".
